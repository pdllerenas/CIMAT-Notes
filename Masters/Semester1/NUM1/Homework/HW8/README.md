# Homework 8

## How to execute (assuming gcc + Linux kernel 6.14.0-28-generic):

To compile and run the first problem, use `make run-p1
ARGS="x0 ex/n.txt ex/taylor/z.txt ex/taylor/fx.txt"`. This
generates a csv table with the interpolated results.
