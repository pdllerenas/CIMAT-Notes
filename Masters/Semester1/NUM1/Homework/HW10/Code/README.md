# Homework 10

## How to execute (assuming gcc + Linux kernel 6.14.0-28-generic):


### Problem 2:
To compile and run the second problem, use `make run-p2
ARGS="ex/2/init/ti1.txt ex/2/init/lambda.txt"`. This generates
a table with the value of the viscosity at `T=1.2` for different values
of lambda.

### Problem 3:
To compile and run the third problem, use `make run-p3-a`, `make run-p3-b`,
`make run-p3-c`. These generate tables for approximations of each function
described in the source code.
